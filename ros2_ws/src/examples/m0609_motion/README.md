# m0609_motion — 홈 → 4개 위치 → 홈 복귀

Doosan M0609가 홈 위치에서 출발해 작업대 위 4곳(P1~P4)을 차례로 정확히 찍고 홈으로 돌아오는 ROS 2 노드입니다.

## 좌표 (베이스 좌표계, mm)

| 이름 | X | Y | Z | 자세 (Rx, Ry, Rz) |
|---|---|---|---|---|
| HOME (관절) | J = [0, 0, 90, 0, 90, 0] deg | | | 툴 아래 방향 |
| P1 | 450 | -150 | 200 | (0, 180, 0) |
| P2 | 450 | 150 | 200 | (0, 180, 0) |
| P3 | 600 | 150 | 200 | (0, 180, 0) |
| P4 | 600 | -150 | 200 | (0, 180, 0) |

각 위치 동작: 접근 높이(Z+100) 이동 → 저속 수직 하강 → 실제 위치 읽고 오차 확인 → 수직 상승.
좌표, 속도, 안전 범위는 모두 `m0609_motion/waypoints.py` 한 곳에서 수정합니다.

## 안전장치
- 움직이기 전에 모든 좌표(접근 좌표 포함)를 안전 작업 영역과 도달 거리로 검증하고, 하나라도 벗어나면 로봇을 움직이지 않습니다.
- 작업대 위에서는 수직 이동만 하고, 수평 이동은 접근 높이에서만 합니다.
- 모션 중 오류가 나면 홈 복귀를 시도합니다.

## 빌드
```bash
cd ros2_ws
colcon build --packages-select m0609_motion
source install/setup.bash
```

## 실행
1) 가상 모드로 먼저 확인 (실제 로봇 없이 RViz)
```bash
ros2 launch dsr_bringup2 dsr_bringup2_rviz.launch.py mode:=virtual model:=m0609 host:=127.0.0.1
```
2) 다른 터미널에서
```bash
ros2 run m0609_motion home_tour
```
실제 로봇은 `mode:=real host:=<컨트롤러 IP>` 로 띄우고, **처음에는 티치 펜던트에서 속도를 낮춘 상태로** 실행하세요.

## 테스트 (ROS 없이 가능)
```bash
cd ros2_ws/src/m0609_motion
python3 -m unittest discover -s test -v
```

## 실제 로봇 적용 전 확인할 것
- **작업대 높이**: Z=200 mm가 작업대 표면보다 충분히 위인지 확인하고 `TARGET_Z`를 조정하세요.
- **TCP 설정**: RG2 그리퍼 길이만큼 TCP가 티치 펜던트에 등록돼 있어야 좌표가 그리퍼 끝 기준이 됩니다. 등록하지 않으면 플랜지 기준으로 움직입니다.
- 주변 지그와 장애물이 이동 경로(Z=300 높이)에 없는지 확인하세요.
